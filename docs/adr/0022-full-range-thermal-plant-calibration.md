# 完整温区热模型标定与供电观测审查

## 状态

Accepted。完整温区采集、审查界面、加热和自然冷却各五分钟及全流程十一分钟是新尝试的成功契约。源码与模拟验收实现这一契约；已部署设备的行为以其固件版本为准，模拟不构成真机热性能证明。

## 背景与决定

五分钟快速标定允许供电扫描结束且加热覆盖至少 100°C 后转入自然冷却，无法提供缺失高温区间的实测散热证据。完整标定以温区覆盖为成功条件，取消固定五分钟完成预算：完成供电边界扫描后，继续在实测边界和电源能力约束内加热至 220°C，同周期关闭加热，再自然冷却至 80°C，通过拟合、完整性校验及 EEPROM 写入与读回校验后才激活结果。供电扫描完成与加热采集完成是不同条件，不得混用。

达到 220°C 不得通过越过供电边界实现。若供电或热结构无法支持目标温度，或发生阶段超时、传感器故障、源掉压及其他保护事件，标定失败并保留旧有效结果及可审查的失败采样，不得以部分温区覆盖冒充完整标定。自然冷却期间保持加热关闭，不主动开风扇，也不为风扇提高供电合同；安全风扇介入仍优先执行，但相应采样不作为合格自然冷却证据。

这是以更长且仍有限的标定时间换取完整高温实测覆盖的选择。本文替代 ADR 0020 的五分钟全流程及最低 100°C 完成条件，以及 ADR 0021 沿用的五分钟全流程预算；其余供电扫描、被动冷却和安全保护边界保持适用。

## 审查界面

- 以温度—申请电压散点与拟合图替换原供电边界曲线，横轴为申请电压，纵轴为每条供电观测的 RTD 理论温度，保留全部有效原始观测；拟合按合同电流分组，对完整显示温区求值。
- RTD 理论温度直接由该条观测的原始 RTD 读数、该份数据对应的分压电路标称参数和 PT1000 理论关系换算，不应用用户 ADC 或温度校准修正，不借用相邻轨迹点的温度。
- 点选显示理论温度、申请电压、合同电流限值、RTD 原始值和采样时间，明确区分不同合同电流的历史观测，当前 3 A 方案不得降流；合同电流不得标为实测负载电流。
- 保留供电采样表，增加 RTD 理论温度列，支持查看全部记录，取消仅能查看最后八条的限制。
- 明确区分当前尝试与 EEPROM 已保存结果，失败尝试的图表不得表述为已生效边界；缺失温区不得表述为已有实测覆盖。
- 失败信息包含原因、发生阶段、累计耗时及未满足的完成条件，区分校准未完成与 EEPROM 写入失败，并说明旧有效结果是否保留。

## 阶段时限

加热阶段最多五分钟，自然冷却阶段最多五分钟，分别从对应阶段开始时计时；阶段内的协商、等待和重试均计入时限，不重置计时。达到温度目标立即进入下一阶段，超时则失败，保留原有效结果及失败诊断采样。旧的五分钟全流程预算不得抢先中断这两个阶段。

全流程从任务开始起最多十一分钟，涵盖环境采样、供电协商、加热、自然冷却、拟合、EEPROM 写入和读回校验，等待与重试不重置全流程计时。阶段超时与全流程超时均独立生效，任何一项到达均不得继续激活不完整结果。

## 验收条件

- 供电扫描在低于 220°C 时结束后，加热采集仍受安全供电边界约束继续进行；未到 220°C 不得直接转为成功冷却和提交路径。
- 达到 220°C 的控制周期内关闭加热，随后采集无主动风扇干预的自然冷却轨迹至 80°C；完整轨迹、拟合及保存校验均成功才激活结果。
- 加热五分钟仍未达到 220°C、冷却五分钟仍未达到 80°C 或全流程超过十一分钟时失败；保护故障及安全风扇介入仍可更早终止标定。
- 失败时原有效标定不被替换；当前失败尝试的采样、原因、阶段和耗时可审查，EEPROM 写入失败与采集条件不足分别显示。
- 散点与拟合图及采样表覆盖返回的全部供电观测，低温记录可直接查看；不将 17.5 V 等后段记录误作首个采样。
- 例如一条原始 RTD 为 1030 mV、申请为 9.5 V / 3 A、分压供电标称为 3328 mV 的观测，应显示约 29.8°C；理论温度不得被用户温度校准悄然改变。
- 不同合同电流的观测可明确区分，图中空白温区原始观测不补点；拟合按合同电流分组，仅供审查，覆盖完整显示温区，不接入供电控制，失败尝试不得标为已生效边界。

## 审查曲线

温度—申请电压图同时显示小尺寸原始散点与拟合曲线。拟合使用按合同电流独立分组、温度缩放后的至多三次最小二乘多项式；每组至少有三个不同温度点，数据不足只显示散点。曲线覆盖完整显示温区，包含实测温区之外的函数求值，悬停说明标注电压 RMS 残差，不能作为可申请电压或安全边界。电压轴默认 5.5–28 V，温度轴默认 25–220°C；观测或拟合超出默认范围时扩展到对应极值。图下选中观测详情最多一行，窄屏横向滚动查看。显示拟合不修改固件供电边界查询及正常加热算法。

## 3 A 电气采集与验收

3 A 方案只约束合同电流为 3000mA，不隐式绑定 60W，也不从固定 PDO 推导 PPS 总功率上限。APDO 广告并允许 21V/3A 时，电压乘合同限流的 63W 不构成降低限流的理由。历史降流观测保留用于审查，不能作为正常 3 A 加热的低电流终点。

首次冷态上探逐档先空载稳定再连续带载至少 200ms 采样，限制搜索自身的温升；后续热态探测连续全导通，按 5°C 温升重探，记录按 5°C 分桶。首次恢复后稳定带载的冷态边界点独立保留，不被同桶后续更高电压覆盖；较早、低电压的粗扫样本保留在原始热轨迹中，不作为正常冷启动的过时电压上限。带载稳定、合同确认及 VIN 跌落保护均是有效观测的必要条件。低温覆盖和接近 3 A 的效果必须由应用已保存标定的正常加热另行验证，不能用采集流程通过或拟合曲线代替。约 30°C、60°C 的实测温度、电流、申请电压及实际电压应可审查；高温切换不得因降低合同电流导致功率下降。正常加热能否达到 220°C 必须单独报告。
