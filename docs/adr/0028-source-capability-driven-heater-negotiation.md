# 按电源实际能力协商加热合同

## 状态

已接受。取代 ADR 0018、0019 中将正常自动加热和标定合同固定为 3A 的条款，以及 ADR 0019 中仅适用于 3A 的边界格式限定。其余传感器、温控、安全关断、VIN 响应和原子保存约束继续有效。

## 决策

`pps3a`、`pps5a` 和历史 `65w`、`100w` 是控制参数库的选择标识，不是电源协商功率上限。正常自动加热、固件热控调优和产品标定从实际选中的 PDO/APDO 获取电流能力，按协议步长向下编码并受硬件 5A 上限保护；不得隐式套用 60W、65W 或 3A 限制。21V/3.25A 电源的正常 PPS 电流请求为 3.25A。显式手动 PPS 调试或台架电源配置可以模拟 21V/3A，正常路径不得自动启用该模拟。

电压仍由当前温度、适用供电边界和控制阶段确定。满输出在已验证边界达到所选 APDO 端点时可以申请该端点，包括 21V；不得固定减去 100mV。低于源端点的温区边界保留既有 100mV 量化裕量，合同变化仍遵守连续调压步长、安全关断和确认等待。低功率保持、冷却和空闲不必维持 21V。协商电压乘合同电流是输入能力参考，不能冒充实际加热功率或实际电流测量。

产品 rapid 标定扫描在整个所选 APDO 范围内申请其实际可用电流。供电边界格式 7 保留原有头部、11 字节点和 EEPROM 容量：tracking 编码 31 表示头部记录的源电流，支持 3A、3.25A 和 5A；格式 6 仅按其原始 3A 语义兼容读取。保留的 detailed 多电流扫描仅支持其可编码的 3A 主机回归场景，不用于产品标定，也不得把无法表示的电流阶段循环执行。

边界记录保存采集时的电流，不重写成新的广告电流。相同电压范围、Wi-Fi 硬件状态及温区下，较高电流能力可以保守复用旧低电流扫描已验证的电压上限：合同申请新电源的实际电流，电压证明仍使用旧记录的电流类别，不能外推到更高电压。较低能力不得复用较高电流记录。VIN 响应与确认合同门禁持续检查真实运行；缺失适用覆盖只能标记估算回退，不得声称已测量。

瞬态拟合、持久化轨迹重建和关热响应使用与该轨迹配对的扫描电流作为显式估算功率基准。完成新扫描时必须使用新边界电流，不能借用尚未提交的旧配置电流。边界和模型仍在全部拟合、验证与读回成功后共同激活，失败保留旧结果。

## 原因

固定 3A 使 3.25A、5A 电源无法提供其广告能力；固定端点裕量使 21V 能力最高只能申请 20.9V。仅更改协商常量会使标定、紧凑记录和模型功率基准不一致，因此协商、采集、编码和重放必须使用同一电流来源。

## 验证

主机回归覆盖真实广告电流编码、端点合同选择、3A/3.25A/5A rapid 扫描终止与记录往返、旧格式来源兼容和显式模型电流基准。主机测试不替代授权硬件上的 HTTP 调优、电压/电流合同读回和完整运行验收。
