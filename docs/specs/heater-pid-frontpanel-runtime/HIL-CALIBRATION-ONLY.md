Their first uninterrupted sampled in-band spans are only `2387/2915ms`, followed by upper exits at `61.53/61.59°C`. These partial spans are diagnostic observations, not valid 10-second witnesses. At the original deadline the controller is already in Hold, so the conditional Approach-extension prerequisite is absent.

The lexicographic score compares its stability-progress component before overshoot and p2p. That component includes distance of the first out-of-band sample, not total later excursion or continuous in-band duration. It is `1.039571` for trial 4 and `1.099773` for trial 5; earlier dimensions tie, so the current point wins despite worse thermal metrics. Trial 6 revisits that point, and its next bounded proposal is already in the proposal cache, ending the target. This proves the current ranking/search cannot converge from this starting profile on this run. It does not establish that trial 5 would pass confirmation or that changing only ranking would suffice. Retained legacy Approach floor/ceiling fields do not control the model trajectory.

The 240°C trials exhibit low-side loss of the stable band, rather than excessive overshoot. The final trial records `0.39°C` overshoot and `2.10°C` qualified-Hold p2p, but its first sampled in-band span is `8272ms`, below the required 10 seconds. Earlier trials often lack physical Hold entirely, and missing Hold p2p remains unavailable. The earlier nine-target saved run imported a prior diagnostic tuning candidate. Its thermal and persistence results remain valid for that seeded condition, but cannot establish calibration-only commissioning. This erased-EEPROM run provides that distinct initialization test and fails. Further work must address calibration-derived initial estimates and the firmware candidate comparison/search, while retaining physical Hold admission, 5% normal Approach minimum, original timing/conditional-extension rules, thermal limits and independent confirmation. Changing the frozen low-temperature strategy is a contract change, not a PD fix or permission to weaken acceptance.
