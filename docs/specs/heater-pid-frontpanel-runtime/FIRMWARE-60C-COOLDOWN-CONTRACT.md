# 固件调优 60°C 冷却起点交付合同

## 范围与基线

本合同仅适用于 `thermal tune --engine firmware` 的 `pps5a` 60°C 目标，覆盖首次试验、每次重试及终止后的冷却。基线为固件主控 5A 调优交付合同及其冻结的外部主控策略。无 `--engine` 的 `thermal tune` 仍执行未修改的外部主控方案。

设备实测温度降至 `<=35°C` 才可开始固件 60°C 试验，与外部主控的温度门槛一致。其它固件目标继续使用既有门槛：低于 `80°C` 为 `<=35°C`，`80°C` 及以上为 `targetTempC - 40°C`。固件调优的冷却周期全程强制全速风扇，不受普通后冷却模式的降速或停机门槛影响。

## 不变约束

- Cooldown 期间逻辑加热请求与最终 MOS PWM 均保持零，风扇持续全速（`fanEnabled=true`、`fanOutputLevel=high`；反相调压硬件为 `GPIO35=high`、`GPIO36 duty=0%`）。所选 PPS 请求和已确认 5A 合同均达到 APDO 上限后才可开始试验；仅满足温度条件不得加热。
- 60°C 的首次试验和所有重试都使用 `<=35°C`；门槛首次满足且 PPS 就绪时立即开始，不增加稳定等待。若仍在等待 PPS，风扇继续全速。
- 60°C 调优终止后，MOS 保持断开、风扇维持全速至有效测温 `<35°C`；恰好 `35°C` 时仍全速，无效测温不得释放冷却锁存。新的正常加热开始时切回既有加热风扇策略。其它目标的终止后风扇释放门槛保持 `<=40°C`。
- 单目标 `20min` 预算仍从 cooldown 开始，覆盖所有试验、重试、PPS 准备和 hold confirm；不得增加独立轮次上限或重置预算。
- 候选生成、seed/插值、评分、hard gate、accepted-target blocking、生产 PID/profile 选择、preview 和 EEPROM 保存保持不变。过冲 `<=3°C`、hold p2p `<=3°C`、full-speed-to-stable 和 `60s` hold 门槛均不得放宽。
- 不修改 PD/PPS 协议或 PowerState 语义；`pps3a` 仍不得加热或产生调优候选。

## 证据与验收

- 每个已开始的固件试验在 `candidate_trial` 事件中记录 cooldown→warmup 边界的设备实测温度和当时门槛。标准五文件报告将两项事实写入该试验数据，并随选中试验展示。历史记录缺少事实时显示 unavailable；渲染器不得用当前策略倒推旧运行的门槛。
- 单元测试证明 60°C 首次及重试试验在 `35.00°C` 开始、`35.01°C` 继续等待；80°C 及以上保持 `target - 40°C`。风扇测试覆盖首次冷却、重试、PPS 等待、终止后 `35.00°C` 的全速保持、`34.99°C` 的释放及无效测温的锁存保持。外部主控回归测试证明其 60°C 仍要求 `<=35°C`。
- 授权 `pps5a` 实机 HIL 须证明 60°C 试验在 `<=35°C` 启动、cooldown 全程 MOS 输出为零、风扇命令全速且 PPS 合同已确认；终止后继续全速散热至 `<35°C`。命令与数字输出不能替代机械转速测量。调优按不变的 gate 如实通过或生成完整失败报告；冷却验收本身不等于九目标资格通过。
