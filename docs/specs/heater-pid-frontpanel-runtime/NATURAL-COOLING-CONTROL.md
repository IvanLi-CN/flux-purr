# 自然冷却模型、补热恢复与候选停滞

## 物理交接与带内失败反馈

同轮搜索同时保留性能失败与真实物理反馈。尚无物理Hold样本、原期限温度低于目标−0.5°C且没有高侧越带的失败，即使处于目标±1.5°C稳定带内，也只能调整Approach，保留全部未使用Hold字段。有效制动配置下界为0.6°C（固定Hold误差0.5°C加0.1°C阶段裕量），上界50°C；sanitize和EEPROM编码必须保留这一边界，固定Hold入口不变。主变换重复时允许沿既有0.4k°C替代步长继续搜索至该物理裕量，不能把旧1°C钳制解释为硬件极限。

同族阻尼高低侧端点均失败且区间宽度≤50‰时，提议在区间中点上减少既有Approach lead一秒，以检查另一响应时间；lead下界仍为零，生产h=max(标定延迟,lead,0.4秒)不变。事件同时记录端点trial、中点与实际lead。较宽区间继续二分，不改变制动、Hold、门槛或运行预算；不同族、缺失端点和非热故障不使用这个反馈。

已及时进入物理Hold、至少30个有效Hold样本全部位于稳定带、过冲≤1.5°C、峰峰值≤3°C，却因PPS请求切换等待中断未验证窗口时，内部搜索允许把Hold基线降至本轮有效逻辑请求中位数（≥50‰且至少比旧基线低20‰），其它字段保持。必须观测到请求改变、当前非接纳样本原始/控制温差≤0.5°C且当时连续Hold计时正在进行；故障、尖峰、纯采样不足、迟到Hold和真实越带不得作为该分支证据。中断计数随所属候选反馈缓存，不能借用另一比较点的采样。拒绝样本仍立即中断稳定窗口和连续Hold确认，不能桥接、填补或升格；新基线须重新实测并完成独立60秒确认。

## 控制合同

3A与5A的普通加热和固件主控调优使用同一生产profile控制器，按[统一控制器决定](../../adr/0017-unified-production-thermal-controller.md)执行。模型输入来自各Device独立保存的thermal-plant标定投影：自然冷却轨迹拟合的对流系数、辐射系数、热容量，以及加热响应识别的传热延迟。冷却曲线不是电功率测量；220→80°C采样范围外的结果是模型外推，不能标为实测曲线。模型不包含全速风扇的主动冷却曲线。

实时RTD测温、原始标定样本的温度重算、模型拟合、运行环境温度及曲线导出共用当前有效ADC映射，包括开发固件允许的假定偏移；用户校准存在时仍禁用该假定。EEPROM与诊断保留未补偿原始电压，不先改写原始值再重复补偿。临时映射形成或移除时须重新标定及取得精确产物资格；仅实时测温应用偏移、模型拟合遗漏偏移的事务不能继续作为种子或有效热模型。

VIN与RTD按各自输入范围配置ADC1衰减和配套eFuse曲线，不能共用不同衰减下的电压转换。网表VIN分压在28V输入时约为2.34V，因此VIN使用11dB量程；RTD保持6dB量程。[ESP32-S3量程规范](https://docs.espressif.com/projects/esp-idf/en/v4.4.4/esp32s3/api-reference/peripherals/adc.html)给出6dB有效范围0..1750mV、11dB为0..3100mV，约21V的VIN输入已经超过6dB范围。任一频道缺失对应eFuse校准时保留读取失败路径。量程修正不改变用户ADC校准点、RTD假定偏移、原码或温度保护；后续标定和调优须由修正后的精确产物重新建立，量程错误本身不证明RTD短时跳变的唯一原因。

标定实时停热仍由分数毫伏测温达到220°C触发，不能为取得样本而继续加热。原始RTD电压以最近整数毫伏保存，因此加热覆盖与持久化重验使用同一原始量化格的上边界，即原始电压加0.5mV后经当前映射换算；该有界误差只用于覆盖判定，拟合和报告继续使用未改写的中心值。相邻低一毫伏且其量化范围未覆盖220°C的样本仍被拒绝；冷却终点、调优温度门禁和传感器保护不使用这个覆盖余量。

ADC1每次新的RTC单次转换在触发前确认SAR状态机空闲，遵循[Espressif的ESP32-S3启动顺序](https://github.com/espressif/esp-idf/blob/v5.5/components/hal/esp32s3/include/hal/adc_ll.h#L907)。启动空闲门禁使用独立同步函数，连续1毫秒未能空闲时该次读取失败，保留原有效样本数量及ADC故障路径。转换已经触发后，忙状态不能阻止读取它自己的完成结果；50微秒快速轮询预算耗尽后仍异步让出执行器。台架转换节奏对照在每次新START前额外保留至少50微秒周转时间，用于检验只等待空闲仍存在的带载异常；该时间不是供应商规定或已证实的根因修复。此边界不改写ADC原码、默认/用户校准映射或实时RTD证据，不用保留控制温度替换异常读数来满足调优门槛；频道切换的5毫秒等待、96次丢弃与完整PWM相位采集继续执行。

调优样本同时保留原始RTD读数 `rawTemperatureCentiC` 与守卫接受的控制温度 `temperatureCentiC`，并用 `measurementAccepted` 标明本次控制周期是否接纳新读数。超过控制斜率/步长的瞬态尖峰只保留为审计事实，不能以保留的旧温度补足有效样本、温度指标、升温率或连续资格时间。拒绝样本立即中断尚未完成的10秒稳定窗口及连续12秒/60秒Hold计时，恢复后的当前接纳读数重新建立计时；已经完整验证的稳定窗口保留为历史见证，真实Hold峰峰值累计不被清除。原始读数须经现有恢复窗口重新接纳，冷却准入同样要求当前接纳读数；壁钟阶段期限、试验超时和目标预算继续运行。`measurementValid` 保留传感器健康判定，故障和原始过温仍立即使样本无效或停热，不能用瞬态过滤掩盖安全事件。主机报告与Web导出独立核验时拒绝将 `measurementAccepted=false` 作为稳定窗口或条件延长的样本见证；旧轨迹缺失该字段按原语义读取，不能据此声称旧轨迹具有新的接纳证据。

测量守卫使用当前实际施加的MOS占空比，包含标定独占输出；普通控制器处于空闲不能被当作标定期间未供热。标定拟合按原始样本的真实时间间隔检查相对于上一接纳温度的斜率，绝对值超过35°C/s的当前读数不作为温度见证，也不能移动下一读数的比较原点；任何包含拒绝读数的温差及被动损失积分窗口不参与拟合。进入冷却超过10秒后，零占空比样本若相对上一接纳温度突然上升超过1°C，同样视为接触/测量异常并排除；这条规则只排除该样本及相邻积分窗口，不改写已记录的原始样本，也不排除停热后的早期余热峰。受128条上限约束，采样器只在首16条启动观测、占空边沿、截止后10秒的500ms节拍以及温度步进达到4°C且距离上一记录至少500ms时写入样本；因此温度步进触发不会以控制周期耗尽缓存。模型重验采用同一排除规则，不插值伪造温度或压缩已记录时间轴。环境起点、220°C加热覆盖和80°C冷却终点须有未排除的温度见证，有效拟合窗口数量及20%物理残差门禁保持。瞬态排除不能代替实时原始过温、开短路或ADC失败保护。

被动损失沿用生产热模型的 `kc × max(T−Ta,0) + kr × max(TK⁴−TaK⁴,0)`，自然降温率为该损失除以热容量、取负号。两类电源不建立第二套能量公式、输出后端或加热状态机；3A不再选择独立plant PI。实际源能力与电阻曲线只改变共享模型的可用供热上限。

Warmup 与 Approach 是两个独立阶段：Warmup 只负责按电源合同全功率升温，不能把 Approach 的输出曲线倒灌到 Warmup，也不能用 Warmup 样本伪造 Approach 样本。模型可以参与 Warmup→Approach 的制动交接预测，但交接后才允许使用 Approach 轨迹控制。

模型有效且已经进入Approach时，欠温恢复由该阶段的50..1000‰轨迹跟踪承担；误差超过制动距离加旧Warmup重入滞回不能使它退回Warmup、清掉轨迹或重新软启动。保留的warmupReenter配置仍约束实时制动距离的既有上界，兼容非模型控制才沿用温差重入Warmup。停热、目标/源类别切换和故障按原生命周期清理状态；固定Hold入口、首次Warmup退出计时及完整确认不因欠温恢复重置。

- 预热仍为全功率及100ms物理软启动。先用 `滤波净升温率−当前自然降温率` 推算在途供热速率，再加回延迟期间的负自然降温率，求原始模型余热距离；后者取 `当前温度 + max(净升温率,0) × 延迟 / 2` 处的曲线值。净升温率已包含当前散热，不能只加损耗而不扣回后续散热。标定参考距离为 `max((最大供热−目标自然损失)/热容量,0) × 标定延迟 + 0.5°C`，按centi°C取整并约束1–50°C，与冷初始化一致。候选相对该参考距离的偏差同时修正原始模型距离，避免动态模型的max运算盖过同运行的减小制动反馈；新标定初值的偏差为零。实际制动距离取候选距离、固定物理Hold误差加0.1°C、修正后模型距离的较大值，模型项上界仍为候选距离加Warmup重入滞回。保留的holdEntry配置不能再设置制动最小距离。候选slope/lead预测继续生效，环境变化仍通过每周期模型计算响应，不把实测斜率替换为初始标定斜率，也不导入历史调优数据。
- Warmup保持独立全功率及100ms物理软启动。Warmup→Approach首个请求立即为50‰；随后每周期跟踪独立生成的期望温度与升温率轨迹，不按标定延迟固定等待，也不把温度下降确认作为恢复供热的必要条件。轨迹使用新标定的自然损失、热容量、传热延迟、实际源能力及候选响应参数，正常逻辑请求约束50..1000‰，保留的profile floor/ceiling不钳制它。已施加VIN、物理MOS占空比及电阻曲线估算的供热按真实时间保存，预测供热到达时的温度与升温率；该估计不是电功率实测。模型前馈与同一未来时刻的温度/升温率跟踪误差共同决定新请求。保护仍可立即停热，普通predictive coast不得把Approach置零。Hold参考为最终恒定目标，沿用现有受保护PI。实际温度仍决定固定物理Hold入口与验收；原稳定窗口、条件延长、独立60秒确认和PD/PPS策略保持不变。
- Approach模型请求的上升沿按本次标定的传热延迟限速：每个控制周期最多增加该周期占传热延迟的满量程比例，至少保留50‰的最小步长；下降请求立即生效，欠温时仍可在有界周期内到达1000‰。这是对模型需求的动态交接约束，不是新的profile floor/ceiling，也不改变50‰硬下限、固定Hold入口或原时限门禁。
- 稳定窗口跟踪与报告必须接收测温接纳状态。被守卫拒绝的样本不能建立或跨越连续10秒窗口；若已建立的窗口被拒绝测温、越过高侧/低侧稳定带或采样间隔超过1秒而清除，报告记录最近一次清除原因，不能只显示笼统的full-speed-to-stable超时。
- Hold 滑行恢复使用跨实际时间的原始温度下降证据：参考原始温度累计下降超过 0.05°C、观察至少 100ms、滤波斜率 ≤−0.02°C/s、连续两次有效观察。温度上升超过 0.05°C、重新播种、目标切换或退出滑行会清除证据。不以每帧温差替代真实降温趋势。
- 恢复还须满足实际与滤波低温误差均达到 `max(holdOn,0.05°C)`，或由自然降温率与传热延迟预测供热到达时将低于该阈值。原始降温和负斜率仍是必要条件，模型不能在温度仍上升时触发恢复。过温和过冲截止始终优先。
- 恢复时 blend 从模型预测的维持损失请求开始，上界为当前候选 Hold 基线，随后交给原 profile PI；不再次从零执行一秒补热爬坡。这是生产路径的显式恢复行为，普通加热与调优相同；不改变 profile 字段的单位或创建仅供调优的输出限制。
- Hold受保护PI、交接blend和欠温补热兜底的最终请求还须受同一在途供热预测约束。以现有供热历史预测标定延迟后温度Tp，取h=max(标定延迟,候选Hold lead,0.4秒)，可恢复功率上限为clamp(loss(Tp)+C×(目标−Tp)/h,0,源能力)。最终请求不得超过该上限；预测仍会过热时可以为零，预测供热到达时将欠温时允许提前恢复。受限周期清除正积分，防止受限期间蓄积补热；blend和兜底都不能绕过约束。这个上限由标定与本次运行的实际供热计算，不是独立profile floor/ceiling，不改变恒定Hold目标、实际温度交接、原稳定窗口或保存资格。无有效模型的兼容路径保留原PI与保护行为。

缺失或无效模型不生成模型预测；生产路径必须由校准就绪门禁阻止进入这条模型 Approach 控制，测试和兼容路径才回退到已有 profile 轨迹。已有无效传感器/电源安全路径保持有效。预测和命令都不得当成热端实测响应。

Approach参考在指令供热到达时刻定义：交接时由已施加供热历史预测标定延迟τ之后的温度作为原点，升温率用来校验未知历史，不与历史输入重复累计。参考状态为温度x与净升温率v，目标为T；h=max(τ,candidate Approach lead,0.4s)，ω=2/h，ζ=clamp(candidate damping/1000,0.1,4)。按真实时间以不超过50ms步长推进 `dv/dt=ω²(T−x)−2ζωv`、`dx/dt=v`。每步将供热 `loss(x)+C×v` 约束在当前源能力5%至100%，再恢复可执行的v，不能假定负供热或超额功率可执行。交接首个5%是独立制动命令，其供热缺口进入在途历史。阻尼调整参考趋稳速度，制动距离/提前量调整Warmup交接，不能改变固定Hold门槛或把Warmup混入Approach。

同一次调优的低温高侧失败在Hold全程停热或仅有入口脉冲、已观察到稳定带后高侧退出时，若Approach请求全程不超过100‰或正常50..1000‰范围内的中位数不超过100‰，优先用观测过冲提前Warmup交接。单个短暂补热峰值不能掩盖低供热后的储热上冲；持续较高供热的试验保留阻尼修正。分类不改变期望温度函数、正常功率范围或通过条件。

同一严格停热Hold/正常Approach证据下，过冲>3°C的制动距离粗步长为 `clamp(round(200×max(overshoot−0.75,0.4)),40,1000)` centi°C，较小过冲保留 `clamp(round(100×max(overshoot−0.75,0.4)),40,500)`；制动距离总上界仍为50°C。持续供热高侧/少量Hold补热的阻尼粗步长为 `clamp(round(1000×max(overshoot−1.5,0.5)),1000,1500)`，总上界仍为4000‰，保留较细的去重备选。粗步长只依据同一次运行的实际过冲生成候选，不能导入历史调优参数；current与predicted均须具有本轮真实试验，保留原期限、完整60秒确认及20分钟预算。

从真实温度积分延迟窗口内已施加的供热减去自然损失，得到供热到达时的预测温度Tp及升温率vp。有效观测还修正模型尚未表达的热传递：同一电压档内相隔至少100ms的接受测温构成能量区间，累计至少max(τ,100ms)有效时间后，计算 `r=(Σloss(T平均)×dt+C×ΣΔT−Σ延迟输入能量)/Σdt`。延迟输入必须覆盖每个区间，否则该区间不能生成差额。只累计档内温差与有效时间，PPS等待、跨档温差、拒绝或重复时间戳均不构成证据。r约束在±实际源能力，未来修正按 `r/[1+(观测年龄+预测时间)/max(2τ,200ms)]²` 衰减，观测年龄超过max(2τ,200ms)时失效；这个有界衰减是预测不确定性约束，不冒充标定拟合出的第二个热常数。已知历史供热加修正后约束0..源能力，不能计算负供热。未覆盖的历史仅由已观测净升温率与自然损失推算，不再叠加r，避免重复供热。参考在同一时刻为x,v，请求为 `loss(x)+C×[v+(x−Tp)/h+0.5×(v−vp)]`，最终约束50..1000‰。供热历史保存于固定64个按真实时间加权的桶，桶宽按2τ+1s适配，兼顾延迟预测和接受测温区间的输入核对。参数或时间异常使模型路径失效，校准、测温与供电安全门禁继续有效。参考与预测按真实控制时间推进，不虚构测量样本。

余热观测只存在于当前加热运行的内存，不保存或导入历史调优数据。累计能量区间的总墙钟跨度也不得超过max(2τ,200ms)，超出后清除旧的未完成累计，不让稀疏档内区间拼成陈旧观测。相邻接受测温间隔超过1s、时间倒退、无效温度或测温故障恢复清空观测；停热、目标或源类别变化、故障还按原规则清空供热历史与参考。PPS切换清除测温区间原点，保留尚未过期的合格差额与档内累计证据，新档首个接受读数只建立原点；等待不能刷新差额年龄。模型未知区间不构成差额证据，观测形成前仍使用原预测，不保证从首个零输出样本立即识别余热。

模型制动控制使用 timing policy `4`，绑定 `modelApproachFloorPermille=50`、`allowedApproachFloorPermille=50` 和生产有效下限 `50‰`。候选配置值仍如实记录用于身份核验，不能抬高实际模型下限。原期限首次检查时仍须处于Approach、尚无期限内有效稳定窗口、期限前取得真实50‰请求且之后未提高非零请求，才可按原有限上限延长。期限、稳定窗口、热指标和独立确认均不放宽。历史policy `3` 保留100‰模型规则，policy `2` 保留100‰配置/Hold派生规则，不能以新政策重写旧报告。

PPS切换只重建RTD观测原点，不清空已施加供热历史、不重新开始参考轨迹、不从跨档温差生成冷却或穿越证据。新档首个接受样本只建立原点，随后才按真实观察间隔更新导数；等待和拒绝读数不构成新观察。正在加热且模型有效的Approach保留有限可信正升温率，负斜率不跨档继承。停热、切换目标/源类别及故障清空参考与供热历史；正常Approach→Hold只清空阶段参考，保留在途供热。Hold滑行恢复仍要求既有档内真实下降证据。

参考温度不因ADC原点偏移重播种，仍按真实时间生成。观测更新只影响跟踪误差，不能修改目标函数、阶段时长或已施加供热；真正测温故障恢复仍清除过滤斜率。

控制和测量分别计时。保持读数不能重复滤波或累计Hold下降确认；同档下一次接受采样使用完整观察间隔。参考、供热预测和调优期限按真实控制时间推进。heaterControlMeasurementGuarded保留，冷却准入仍要求当前接受采样且未处于保护等待。

## 搜索合同

未验证窗口的期限失败只有一两个物理Hold样本时，不足以支持Hold供热修正，但不能丢失Approach到达时间反馈。完整正常Approach请求、可调热失败、没有高侧离带、过冲≤0.5°C，且首次物理Hold与当前稳定窗口起点均晚于原允许期限时，可作为同轮单通道区间的低侧端点。参数点、真实Hold样本数和实际超时时间保持；中点只能改变该区间的制动距离或阻尼，不能填补资格样本、放宽期限或改动Hold参数。已及时交接、三个以上Hold样本、真实高侧及非热失败不能借用此边界条件。

仅沿提前制动单一有效通道的主提议若覆盖全部允许起测温差，内部搜索先将观测粗步长逐次整数减半；每个候选仍通过原制动温差检查、sanitize和有效点去重。步长低于40centi°C即结束该本地检查，未找到新点才沿原有备选通道继续；这不是额外物理试验，不暂停目标预算。其它有效字段同时变化、反向制动或未超起测边界的提案不采用此缩步。原Warmup全输出证据及资格仍由真实试验取得，合法静态距离不能直接证明预热或候选通过。

低温高侧余热的严格停热Hold分支若完整Approach请求均在50..1000‰且存在高于50‰的模型补热，阻尼达到4000‰上界后须检查既有Approach lead响应时间通道，主提议只增加2秒、上界12秒，保留制动距离和全部Hold参数。同类重复提议的偶数阻尼备选已到界时，改为单通道增加2k秒lead（k为原有1–8级），仍经过sanitize与有效点去重；奇数制动备选保持原规则。该参数同时参与既有Warmup交接预测和h=max(标定延迟,lead,0.4秒)轨迹响应，不能只把微增制动当成全部剩余控制能力。全程50‰、严重低供热余热的优先制动分类、真实低侧、持续Hold供热、已验证窗口和非热故障不由此改变方向；生产公式、参数总边界、原期限、条件延长、独立60秒确认及保存要求保持。

固件engine的失败Scout直接作为该组比较的current实测：缓存其完整profile、实际十一维分数及对应失败反馈，然后只冷却并加热不同的predicted候选。设备决策账本记录 `batch_current_reuses_completed_scout`，原Scout样本、trial身份与判定保留，不创建虚拟BatchCurrent试验或复制采样。比较仍使用两套实际参数各自的真实反馈；较优的合格短试验点必须另行完整60秒确认，失败点不能凭缓存取得通过、稳定窗口或保存资格。外部runner流程不变。

完整Warmup输出有效性仍为比较第一优先级；同为失败的候选中，已退出Warmup的真实Approach/物理Hold进展优先于预热超时。尚未退出Warmup没有Approach期限温度，缺省分数不能比真实期限欠温更优而使内部搜索选择不可调的旧失败。该排序只决定下一提议的反馈来源，所有失败资格保持。兼容高侧阻尼比较已证明加强阻尼无改善且支持提前制动时，既有提前制动分支必须先于普通重复提议备选，避免通道再次饥饿。

同一次运行、同一≤150°C目标保存最多八个已实际测量的Approach失败端点，共用有界缓存。完整正常Approach请求范围50..1000‰且并非全程触底、未验证窗口的期限失败才可记录：高侧端点要求真实入稳定带、至少三个物理Hold样本、Hold最低不低于目标−1.5°C而最高超过目标+1.5°C；低侧端点要求未观测Hold且期限温度低于稳定带，或未发生高侧离带、没有超过目标0.5°C且期限仍低于固定物理Hold入口。进入±1.5°C稳定带不等于达到目标−0.5°C的物理交接入口。端点只允许一个有效通道不同：阻尼区间的较小阻尼为高侧、较大阻尼为低侧；制动距离区间的较小距离为高侧、较大距离为低侧。优先选择最窄兼容实测区间的整数中点，只改变该通道，再真机试验；已有阻尼区间优先，否则检查制动距离区间。每个中点经过sanitize、Warmup温差余量、32点去重和原资格门禁；它是候选提议，不是假定温度响应单调或已经通过。保护零请求、故障、已验证窗口、全程触底或同时改变两个有效参数的端点不能合并。跨目标和新运行清空端点；历史报告、EEPROM调优结果及另一电源类别均不能提供端点。

180–220°C 的模型轨迹若在原时限内完成物理Hold交接，随后从稳定带低侧离开，不能继续把这段失败当作Approach交接不足。未验证窗口且原性能门槛失败时，至少三个Hold样本、完整正常Approach请求范围50..1000‰、Approach与Hold请求中位数及Hold p90均≥950‰、Hold平均欠温>0.2°C及最大欠温>1.5°C、过冲≤1.5°C、峰峰值≤3°C，支持维持供热整改：Hold基线增加100‰、reheat增加80‰并不低于新基线（均上界1000）、holdLead减1（下界0）、blend取1。预热交接、Approach参数、保护、PD/PPS、稳定期限和温度门禁保持。此分支不要求三个零输出样本，区别于波动/滑行恢复分支；scout/batch和确认失败共用入口。缺失物理Hold、迟到交接、高侧、保护零请求、窗口已验证或非热故障不得借用；参数无有效变化时继续既有去重/有界搜索，不能重复同点。

外部 runner 的候选策略保持冻结。固件 engine 的有意例外包括既有高温高侧保守变换，以及 Hold 恢复变换：真实曾进入稳定带、随后低侧离带、至少三个 Hold 样本、Hold 逻辑请求中位数 ≤100‰、过冲 ≤3°C 时，优先减小 holdOn 5 centi°C（下界5）、提高 reheat 80‰（上界1000）、提高 Hold Kp 20（上界1000）、blend 取1。该输入不能被 Approach 的 Underpowered 分类覆盖。高侧保守保护与非热故障拒绝仍优先。此例外覆盖 scout 与确认失败，不声称与冻结旧策略逐值一致。

160–240°C 的高侧保守变换同时覆盖未验证窗口的稳定门槛失败与超过3°C的热指标失败；两者均须原始温度证实高侧越带或高侧未入带。稳定窗口失败后继续提高 Approach 下限不能由 Underpowered 标签单独辩护。已验证窗口后的普通离带不触发这个稳定失败例外。具体有界变换与完整验收按整改合同R2执行；外部runner保持冻结，全部固件目标的失败比较和重复提议处理采用下述内部搜索规则。

已在原性能门槛内建立并验证稳定窗口，但 Hold 发生双侧波动时，满输出不能直接当作 Approach 供热不足。若首次离带为低侧、至少三个 Hold 样本，零逻辑输出至少三个样本且占比≥5%，过冲在0.5–3°C、峰峰值大于3°C且不超过4°C、Hold 请求中位数≥900‰及p90≥950‰，且当前 Hold/reheat 均≥900‰，则仅修正保温参数：Hold 基线减100‰（下界700）、reheat减100‰且不低于基线、holdLead减1（下界0）、holdOn减5 centi°C（下界5）、blend取1。预热、Approach、物理阶段入口和通过门槛不变。该分支覆盖短试验与确认失败；缺失证据、单纯持续低温、性能门槛失败或非热故障不能触发。高侧保护仍优先，完整点去重仍在生产sanitize之后执行。

180–240°C 已在原时限内交接到物理 Hold，而稳定窗口随后低侧离带时，保温供热不足须保留独立补热与恢复时机的调整余量。若曾进入稳定带、至少三个 Hold 样本及三个零请求样本、过冲≤1.5°C、峰峰值≤3°C、首次离带为低侧、Hold 请求中位数在101–949‰且p90有效且≤1000‰，并满足下列任一真实Approach条件，则保持 Hold 基线、预热和 Approach 参数，仅提高 reheat 80‰（上界1000）、holdOn减5 centi°C（下界5）、holdLead减1（下界0）、blend取1：兼容高输出轨迹的请求中位数与配置下限均≥900‰；或者模型制动轨迹中至少三个Approach样本全部请求正常下限50‰且中位数为50‰。模型路径不依赖已不参与有效输出的旧配置下限，不能仅凭中位数、缺失采样或任意正常低输出推定全程下限制动。PI 请求的p90达到1000‰不等于配置的reheat达到上界；reheat已到上界时，仍可有界减小尚有余量的holdLead/holdOn。完整点没有变化时不产生提议，并由原停滞门禁结束搜索。没有及时物理交接或缺失采样不能触发；高侧保护仍优先。短试验与确认失败采用同一证据入口，不能据此放宽稳定门槛。

固件内部失败候选比较使用完整试验采样前缀：保留安全、完成状态与热指标门禁的优先级；同类未验证窗口的失败先比较首次入带后整个前缀的最大越带量，再比较满足至少3Hz、没有超过1秒采样中断的最长连续带内时间，随后比较真实热指标与既有时间表现。已入带前缀的可行性不能被更早入带、随后仍越带的较长截断片段覆盖；较慢但越带更小的候选保留进一步阻尼修正的机会。未入带仍按期限缺口排序。首次越带单点保留用于方向分类和审计，不能代替整段稳定性；不完整窗口仍失败，评分改善不构成确认资格。成功候选的比较及独立60秒确认不变。此规则覆盖全部固件目标，外部 runner 的评分与候选策略保持冻结，不声称逐值等价。

current/predicted比较后，已满足短试验资格的胜出点仍须独立60秒确认。胜出点若仍失败，内部搜索直接使用该点在同一次比较中的真实失败反馈生成不同的有界候选，再开始Scout，不原样重跑失败胜出点。current反馈在切换到predicted前单独保留；current胜出时不得借用predicted温度或失败方向，predicted胜出时不得借用current反馈。缓存只用于下一组参数提议，不补写当前试验、窗口、分数或通过结果；比较结束、目标切换和新运行均清空。缺少所选点的匹配反馈、可用方向无不同有效点或原预算耗尽时安全结束目标。候选身份和RAM预览随新参数更新，保存与完整确认门禁不变。

每目标保存最多32个提议点的完整参数。候选在生产 sanitize 后若与当前相同或已被提议过，固件须在同一失败方向内检查尚有余量的有效参数，生成不同的有界点，而不是立即结束目标。高侧余热可增加制动距离或阻尼；已进入物理Hold后的高侧/低侧失稳优先调整Hold/reheat或PI；未交接的低侧缺口可减小制动距离或阻尼。每个替代提议只调整一个通道，缺失Hold不得支持Hold补热修正，采样/供电/通信/安全故障不得生成替代点。保留的Approach floor/ceiling字段不得作为模型轨迹有效变化的替代。合法方向无剩余不同点、记录容量耗尽或原20分钟预算到期才结束目标，保留 `candidate_search_exhausted_no_distinct_safe_proposal` 和区间阻断。current/predicted比较及accepted点冻结保持，不重复加热已知点，不宣称搜索耗尽证明硬件极限。

未交接到物理Hold的低侧失败在scout/batch和确认reseed中保留原Hold基线、reheat、入口/退出曲线配置、on/off、PI、blend、lead及过冲截止值；零个Hold样本不能支持这些通道的反馈。主提议的有效Approach参数已到边界时，生产sanitize后的去重必须转入原有有界制动/阻尼替代搜索，而不是通过修改尚未参与供热的Hold设置消耗下一轮实机试验。真实已观测Hold、高侧保护和非热故障拒绝仍遵循各自原有证据规则；外部runner保持冻结。

同一次运行、同一目标、同一有效参数点已真实进入稳定带并在至少三个Hold样本后低侧离带时，内部搜索保留该失败的参数点、反馈和来源trial，最多保存最近两个不同有效点。随后同点的未交接低侧失败不能抹掉这条既有Hold供热证据。只有当前失败可调、过冲≤3°C、缺失Hold且同方向的实时制动/阻尼替代点全部重复或到界时，才使用匹配点的已观测反馈检查既有单通道Hold/reheat/Kp/on有界替代点。不同有效点、目标或运行、当前高侧失败、采样溢出及非热故障不能借用；新运行和目标切换清空缓存。提议记录来源trial，每个新点仍须重新实测及独立60秒确认，缓存不能填入当前trial的温度、窗口、Hold样本、分数或通过结果，不能读取历史报告或EEPROM调优结果。生产控制律、参数边界、正常5%下限和全部资格门禁不因此改变。

冷初始化只允许使用新标定的加热/自然冷却曲线、模型、源能力和生产常量；搜索反馈只能来自同一次运行。禁止以已保存bank、历史candidate或另一运行的trial作为初值。约三次候选修正是收敛目标，不是第三轮自动通过规则。

未验证连续窗口的重入带起点仍是原始诊断事实，不能降低评分中的性能门禁缺失罚项。只有已完成10秒验证的窗口时间可作为已测得的稳定性能比较；失败记录仍保留实际重入带起点，不伪造稳定窗口或修改报表的原始时长。越带量与采样分档只作用于内部失败排名，不能改变真实资格判断。

重复提议的替代点使用最多32次有界本地检查，不触发32次物理加热。第k级（1–8）每个点只改变一个参数：高侧Hold基线减20k‰（下界50且不反向提高）或Kp减2k（下界8且不反向提高），高侧制动距离加0.4k°C（上界50°C）或阻尼加100k‰（上界4000）；低侧物理Hold已有至少三个样本时，reheat或Hold基线加40k‰（上界1000）、Kp加4k（上界1000且不反向降低）或holdOn减0.05k°C（下界0.05°C且不反向提高）。缺失Hold的低侧仅减少制动0.4k°C（下界0.6°C）或阻尼100k‰（下界100）。对每个已入缓存的候选忽略不参与模型输出的保留Approach floor/ceiling再比较有效点，不以变化身份重新加热同一有效参数。已获准的主变换仍优先，替代点仅在主提议重复或无有效变化时使用；安全、热门槛与确认规则不变。

高侧减能主变换的旧数值下界不能反向提高标定初始化的Hold基线或Kp：原值已经低于下界时保持原值，仍可调整有余量的制动或其他参数；原值在旧范围内时保留既有变换。reheat不得低于变换后的Hold基线，也不得因为这项兼容处理增加原请求。该规则覆盖短试验与确认失败，不改变生产控制律或资格门槛。

未完成稳定窗口的评分先比较整个前缀的最大越带量，再按固件名义采样间隔200ms对连续带内时长向下分档，同档继续比较真实热指标。亚采样间隔的端点抖动不得决定保留更差温度轨迹。原始时长仍完整保留；真实10秒窗口验证、期限与成功评分均使用原有精度，不采用分档。对于至少三个物理Hold样本且逻辑请求全为零的高侧余热，重复主提议的替代点优先检查有界阻尼，其次检查制动距离，不调整未参与供热的Hold/reheat或PI。

低温目标（≤150°C）的未验证窗口高侧失败，若真实曾入带、首次从高侧离带、至少三个物理Hold样本且这些样本的逻辑请求全部为零，则先修正入口余热而不是补热基线。首个Hold样本允许一个不超过50‰的交接脉冲，其余样本必须全为零；必须保留首个样本的真实请求值，不能以中位数为零代替这个逐段判断。后续任意非零请求、首个请求超过50‰或缺失入口事实均不能使用此例外。相同余热判断用于重复提议后的阻尼/制动替代点。未满足全程下限证据时，内部搜索先提高模型Approach阻尼：粗搜索步长为 `clamp(round(max(overshoot−1.5°C,0.5°C)×1000),500,1000)‰`，总值上界4000‰；该步长避免在仍然越带时反复进行250‰的小修正，重复或达到边界后保留较细的有界替代点。这一阻尼分支保留预热交接距离、Hold参数、控制公式和门槛。这项同运行反馈变换优先于普通减能分支，覆盖短试验与确认失败；阻尼已到上界、缺失或持续供热的Hold、低侧失败、已验证窗口或非热故障不触发，继续既有有界搜索。外部runner不采用此差异。

低温高侧余热方向分类、阻尼主提议和重复提议替代点也接受入口前250ms内不超过100‰、至少90%完整Hold样本停热的严格短脉冲证据。入口窗口后任意非零请求均撤销这一例外；不能把持续补热、迟发补热或单纯中位数为零作为停热。真实物理Hold温度若一直在稳定带内或高侧、随后高侧越带，Approach的先前低侧单点不能将这段失败分类成Hold缺热；原始单点和资格判定保留。

同一低温余热分支若至少三个真实Approach样本全部请求50‰，增加阻尼不能再降低已触底的供热，主提议须优先增加既有制动距离，步长为clamp(round(max(overshoot−1.5°C,0.5°C)×100),40,100)centi°C，上界50°C。证据只统计Approach，不能混入Warmup或用中位数代替全样本判断；任意零请求、超过50‰请求或不足三个样本均不能建立全程触底证据，每轮清除统计。Hold入口脉冲和其余停热要求沿用上述严格余热判断。重复提议时仅沿提前制动方向，以40centi°C递增检查最多32个替代点；达到制动边界且没有不同有效点时结束搜索，不用未施加的阻尼变化冒充进展。此分支只改变同运行内部搜索的参数选择，不改变生产控制公式、独立Warmup全功率、Hold参数、阶段入口、5%下限、条件延长或独立确认门禁。

低温目标（≤150°C）的未验证窗口高侧失败，若至少三个真实Approach样本的逐样本逻辑请求范围全部位于50–1000‰、至少三个物理Hold样本全部停热、已入稳定带后从高侧离带，并且完整Approach最大请求≤100‰、中位数≤100‰或过冲>3°C三者之一成立，则优先修正预热储热：制动距离增加 `clamp(round(max(overshoot−0.75°C,0.4°C)×100),40,500)` centi°C，保持其余参数，上界50°C。Hold允许入口前250ms内不超过100‰的短脉冲，但至少90%的完整Hold样本必须停热，入口窗口后任意非零请求均撤销此例外；每次试验单独记录脉冲位置，不能只凭中位数为零判断。严重停热上冲不依赖100‰中位数分类，较小过冲且请求中位数>100‰则保留阻尼分支。逐样本范围只统计Approach，不包含Warmup；任何保护零请求、持续或迟发Hold补热、已验证窗口或非热故障均不触发该分支。此证据不是“全程50‰”，不得形成条件延长资格；原floor-only统计和时间门禁独立保留。重复主提议时只沿提前制动方向检查既有40centi°C的有界替代点，不能通过增加Approach阻尼冒充预热能量修正。该规则覆盖scout/batch与确认reseed，使用同一次运行的真实失败反馈，不导入历史调优。

首次稳定带离带值保留为原始事实，不能独自决定后续物理Hold的缺热方向。已真实入带、至少三个物理Hold样本、Hold全程停热（或既有单个≤50‰入口脉冲）且物理Hold最低温度未低于稳定带、最高温度超过目标+1.5°C时，内部搜索以完整Hold高侧余热修正为优先，不能因Approach中的一次低侧抖动提高Hold/reheat或PI。真实Hold低侧恢复要求其已采集的最低温度确实低于目标−1.5°C；未采集该物理事实的历史策略向量沿用原诊断投影，不补造证据。此规则改变失败反馈方向，不能免除离带失败、稳定窗口、原期限、条件延长或独立确认；原始first-exit、温度、请求与报告记录均不重写。

低温目标（≤150°C）的未验证窗口失败若已真实入带、至少三个物理Hold样本、实际Hold最低温度未低于目标−1.5°C且最高超过目标+1.5°C，少量补热不能令搜索继续扩大预热制动距离。当完整Hold采样至少80%停热、逐样本最大逻辑请求不超过100‰，且完整Approach请求均不低于50‰、存在超过100‰的模型补热时，下一主提议仅提高有效模型阻尼，采用上述500–1000‰粗步长及4000‰上界，保持制动位置和全部Hold参数。最大请求由完整输出直方图取得，不能用中位数或90分位隐藏较大的脉冲；缺失最大请求事实不得使用该分支。这是有限Hold供热下的高侧反馈，不是全程停热或入口短脉冲证据，不取得任何下限或条件延长资格。相同物理Hold高侧事实优先于Approach的历史低侧单点，但原始首次离带事实仍保留。重复提议时先检查同方向有效阻尼/制动替代点；真实低侧Hold、持续补热、较大脉冲、Approach保护零请求、已验证窗口和非热故障不得触发。短试验与确认失败共用该反馈；每个新点仍须实测并独立60秒确认，生产控制律、PD/PPS和全部资格门禁保持。

## 风扇采样与标准报告

设备样本新增可选 `fan={enabled,pwmPermille,outputLevel}`，取已经施加的生产风扇命令。事件摘要包含该对象；CLI 与 Web 采用同一字段顺序验证。旧记录缺字段时原摘要保持一致，报告显示 unavailable，不能填零或补造历史数据。

标准五文件报告增加风扇图，与温度、输出、电压、电流图共用 trial、时间范围、phase 分界和联动指针。使能开为100%、关为0%；PWM 显示 GPIO36 的反向调压信号，使能开且 PWM=0‰ 为全速命令。使用阶梯曲线表示采样间保持的命令，不伪造连续变速。硬件没有转速反馈，图不宣称实测转速或风量。冷却仍必须全程 MOS=0、风扇使能开/PWM=0‰，直到满足原起点门槛。

进入初始冷却后，在首个控制采样前经共享风扇策略施加全速命令；样本不能先记录旧的待机命令、再补写硬件。试验结束后的冷却继续在同一控制周期关闭 MOS 并施加全速风扇。

## 验收

软件验证覆盖不同真实控制间隔的缓慢降温恢复、模型对制动与补热时机的生产路径影响、原3A模型数值、饱和低侧失败方向、候选不变/循环终止、风扇对象跨语言摘要和旧摘要兼容、报告切换与跨图联动。

实机使用同提交 ELF、已授权精确端口和标准 CLI/devd 流程。先验证身份、对应3A/5A PPS能力、板级RTD激励、模型、HOT=LOW、无 preview 冲突，再执行诊断与完整八目标调优。五文件、连续事件、候选/preview 身份及独立60秒确认均须可复核；软件测试通过不代替 HIL，失败记录不代替资格通过。

固件engine调优由生产输出后端管理自动PPS；开始前状态必须明确为manualPpsEnabled=false。CLI在改变运行模式或发送start之前拒绝已开启或状态未知的手动覆盖，不替用户自动清除。清除覆盖应先停热，再通过标准pd pps clear执行并读回；标定任务自己的受保护PPS所有权与调优无关。手动覆盖下取得的轨迹必须保留其配置事实，不能作为自动生产控制的合格HIL或保存依据。

稳定窗口证据保留首次完成的连续10秒区间：开始时间和首次验证完成时间一经验证不再被后续 Hold 样本改写。后续60秒保温继续独立积累过冲和峰峰值，不能把后续离开绝对稳定带的样本纳入此前已验证的窗口，也不能用固定窗口掩盖后续保温门禁失败。标准报告从该明确区间的真实样本复核证据；设备 adopted 与报告资格通过分别保留。

`--seed-profile-file` 支持普通 profile 与标准 `thermal-profile.candidate.json`。v2 导出从 `profile.value` 读取完整点值，显式零提前量不能触发旧字段继承；往返物化必须保持参数与摘要。错误功率类别、缺失 settings 或目标点的输入在取得设备 lease 前拒绝，不能静默替换为默认 seed。

v2 seed 按完整 wire profile 导入，保留 settings 与各 point 的独立值、整数精度和显式零。导出必须覆盖有序九目标；不能插值补齐缺失目标，不能重新从首个 point 构造 settings。非规范参数、错误 bank 或携带不匹配 `candidateHash` 的文件在取得 lease 前拒绝。普通旧格式 profile 保留既有继承与九目标物化路径。

候选导出只能携带与 `candidateHash` 一致的完整参数。中断时若只取得当前摘要而未取得对应参数，`profile.value` 为 null、`profile.source` 为 `unavailable_matching_candidate_profile`，不能借用旧候选或启动 seed 的参数补齐。原始日志保留已取得的历史参数与采样；缺失当前参数不能形成可保存候选。
