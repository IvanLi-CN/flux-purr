## 预检与边界

预检发现 OvO 保存功率为 60W、5A 标志关闭，但 `pps3_limit_ma` 曾回读为 5000mA。通过 released `isolapurr` CLI 将能力明确设置为 60W、PPS 3000mA、5A 标志关闭，并立即回读确认 `matches_config=true`；测试期间每条样本的电源配置均为该值。测试开始前加热台为 27.8°C、heater 关闭、源端为 5V 固定空载。

## 冷态自动升温

正式采样从 29.29°C 开始，记录 720 条样本、761.061 秒，最高温度 139.26°C，目标温区 138–141°C 共 502 条样本。阶段计数为 Warmup 211、Approach 7、Hold 502；所有样本的设备状态和电源遥测均有效，源端错误数为 0，运行恢复计数为 0，配置不一致数为 0，设备 uptime 没有回退。

自动控制最高申请/确认电流为 3000mA，最高申请/确认电压为 14000mV。OvO USB-C C 口实测电流范围为 45–2268mA，最高实测输入功率为 31648mW；低电流样本对应电压切换或 PWM 低占空阶段，均为 `status=ok` 且相邻样本恢复，不是掉电或过载重启。PWM 范围为 0–100%，其中目标温区持续按功率需求调制。

## 独立 HOLD

在同一次自动加热会话中追加 90 条样本、87.716 秒，90/90 条均为 `hold`。温度范围为 138.33–139.31°C，PWM 范围为 69–87%，申请和确认合同固定为 14.0V/3A。OvO 实测电流为 1447–1939mA，最高实测输入功率为 27127mW；源端错误、设备状态错误、恢复计数和 uptime 回退均为 0。

## 收尾与结论

停止加热后，设备读回 `heaterEnabled=false`、逻辑和物理 PWM 均为 0；源端切回 `auto_follow` 后回到 5V 固定合同，实测约 114mA/578mW，SW2303/TPS 错误锁存和恢复计数均为 0。

本卡对授权的 3A 范围判定 A6 通过：自动加热在冷态启动、升温放宽、目标 HOLD 期间始终处于 3A 电源能力边界内，源端保持在线且没有过载重启。3A 是电源能力上限，不是加热负载必须达到的电流；实际负载电流由安全电压、功率需求和 PWM 共同决定，因此低于 3A 不构成失败。

OvO 的 USB-C C 口遥测是本次记录的电源侧实测电流，不是独立夹表或示波器测量；若将“独立外部探头”作为额外合同门槛，该仪器证据仍需另行补充。本次正式硬件证据不使用旧的 formal self-test 3Hz 判定：该 runner 的串口 `/status` 往返中位数约 489ms，触发的是主机采样率门禁而非电源故障；A6 结论以本卡的持续直接遥测为准。
