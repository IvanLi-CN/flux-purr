## 预检与边界

OvO 通过 released `isolapurr` CLI 回读为 60W、PPS、`pps3_limit_ma=3000`、`pd_pps_5a=false`、`sw2303_profile_applied=true`、输出开启。设备刷写后身份回读为 `d0cf1308a148`，固件能力包含 `thermal_plant_run`、`usb_jsonl` 与 `flash_preparation`。冷态开始前设备约 33.6°C、heater 关闭、空载为 5V/1A；整个运行只有主人授权端口，没有切换 USB 路径。

## 冷态自动升温

候选 `v3` 从 33.61°C 开始采样 180 条，时间为 2026-10-22 09:21:30Z–09:39:04Z。请求电压按实测边界逐级从 7.7V 提升到 20.0V，没有再次出现 8.4V 与 8.9V 之间的回退循环；所有确认合同均为 3,000mA，申请/确认电压序列包含 7.7、8.0、8.4、9.4、10.3、11.2、11.9、13.6、14.4、15.4、17.1、18.5、18.8、19.8 与 20.0V。OvO C 口输入电流范围为 1,662–2,928mA，输入功率峰值为 58,259mW；在 20.0V 满功率阶段电流约 2.84–2.92A，满足 3A±200mA 的电源侧电流目标。源端 profile 全程已应用，源端输出在线，设备 uptime 没有回退，温度最高 197.81°C。

这次采集证明的是设备端合同确认、电压晋级、满导通阶段和板端温升轨迹；低电压阶段的 OvO 输入电流只属于 HIL 审查，不能用来反推加热板电阻或非加热功耗。`contractMa=3000` 是设备端安全上限，`sourceCurrentMa` 是报告用的整机输入遥测，两者不能混用。

最终固件在同一授权端口完成一次受控满功率确认：2026-10-22 10:15:06Z–10:21:51Z，温度从约 26.9°C 升至 179.5°C，申请电压从 7.7V 连续提升到 20.0V；20.0V/3A 合同从 10:20:49Z 起保持超过 60 秒，OvO 输入电流为 2,827–2,925mA、输入功率为 56.4–58.3W，源 profile 全程已应用。期间发生的少量 status 轮询 lease 冲突只造成采样空洞，没有改变设备输出或源端状态。原始记录为 `/tmp/flux-purr-a6-final-v4-ramp-20261022.ndjson`。

## 目标温度与 HOLD

冷态满功率运行在 20.0V/3A、物理 PWM 100% 下达到约 197.8°C 后进入热平衡，没有达到 220°C。随后将目标设为 200°C，追加 90 条、约 8 分钟的独立采样；温度范围 197.53–198.69°C，所有样本仍为 Warmup、20.0V/3A、物理 PWM 100%，OvO 输入电流 2,832–2,839mA，未进入 HOLD。因此 A6 的“220°C 覆盖及 HOLD 持续 60 秒”门槛仍未完成，不能宣告 A6 全部通过；证据显示阻塞点是 60W/3A 链路与当前板的热平衡，不是电压晋级循环或 PD 过载断电。

## 收尾

停止加热后设备回读 `heaterEnabled=false`、`heaterPhysicalOutputPercent=0`、`mode=idle`；冷却期间风扇正常运行。最终候选温度降至约 36.6°C 后，OvO 自动回到 5V/1A 空载，约 115mA、约 0.58W，未发现 SW2303/TPS 错误锁存、源端掉线或设备重启。
