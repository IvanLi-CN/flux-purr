# A6 3A 电源边界 HIL 验收标准与证据

本卡的“当前验收标准”是 A6 3A 电流边界 HIL 的规范；后面的运行记录是历史证据，只有满足下述两阶段顺序和来源绑定才可重新判定为当前通过。5A 不属于本次范围，也没有执行 5A 测试。产品校准仍使用设备端保存的 RTD/VIN 原始 ADC、3V3 假设、PPS 请求/确认、PWM、WiFi 状态和温度稳定性；OvO USB-C C 口遥测只用于 HIL 报告的电源在线/负载审查，不进入校准算法、EEPROM 边界或自动加热查表。电源侧电流代表整机输入，不是加热板端独立电流。

## 两阶段运行顺序（强制）

1. **阶段一：校准运行。** 使用 `thermal_plant_auto` 完成受保护的供电边界扫描、热模型拟合和原子提交。该阶段的扫描点、终端探针、低电流升温点和冷却点只能作为校准诊断证据，不能作为 A6/HIL 正常加热验收样本。
2. **阶段一结束条件。** 主机必须读回 active calibration transaction/model identity（至少包含 `calibrationRunId`、transaction/revision 或等价 identity、model digest）并确认提交成功；没有这次读回，阶段二不得开始，整轮只能是 `incomplete`。
3. **阶段二：验收运行。** 在阶段一读回成功后，重新创建独立 `acceptanceRunId`，关闭 calibration/manual-PPS 模式，确认正常自动加热实际应用阶段一的 active calibration identity，然后从冷态开始新的全逻辑功率加热测试。验收 HTML 必须只从阶段二的原始同步采样生成；不得把阶段一数据拼入阶段二曲线或用阶段一数据填补阶段二缺口。
4. 阶段二 PPS Warmup/全速的逻辑请求和物理门控均必须为 `100%` 静态全导通；Warmup 直接申请当前校准安全上限，不使用普通 500mV 请求步进，避免在相邻 PPS 合同之间反复协商。进入 Approach/Hold 后，降低功率必须优先保持仍处于最新安全上限内的已确认 PPS 电压并使用 PWM；只有安全上限收紧或确需更高安全合同时才重新协商。协商、保护降压和故障关断可记录显式 `0%`，但 `1..99%` PWM 软启动或中间占空比会取消该运行的全逻辑功率证据资格。

## 当前 A6 验收标准（规范）

### 试验边界

1. 目标是 7cm 加热台、60W/3A OvO C 口电源、正常自动加热和已确认的 3,000mA PPS 合同。`contractMa=3000` 只是电源合同上限，不是实测电流。
2. 起点必须是室温冷态，板温 `T_start <= 35°C`，heater 先关闭并完成源端 profile/PD 状态检查。
3. 设备必须以 GPIO47 静态 `100%` 门控（非中间占空比 PWM）满导通升温；校准扫描和终端探针只允许 `0%`（协商/保护关闭）或 `100%`（合同确认后的静态全导通）。不得使用 1–99% PWM 软启动替代这项证据；手动 PPS 调试不属于本 A6 证据范围。
4. 申请电压必须以低到高的主序列推进到精确的 `21.0V`；安全重协商允许短暂回退，但必须有 PWM 归零和不超过 2s 的边界。21V 终点使用校准专用的功率安全电流 `floor(60,000mW / 21,000mV)`，按 50mA 步进向下编码为 `2,850mA`；不允许发出 `21V × 3A = 63W` 请求。每个样本的 OvO 实测输入功率必须保持在已授权的 60W 能力内。APDO 不支持 21V 时，验收失败，不得改用 20V 冒充终点。

### 阶段一校准边界记录（不构成阶段二验收）

以下低压升温、3A 覆盖和 21V/2.85A 终端探针条件属于阶段一校准边界记录。它们用于确认校准事务可提交以及 60W 电源的安全边界，不能单独证明“应用校准数据后的正常自动加热”通过。阶段二必须重新从冷态启动，并按两阶段运行顺序只使用阶段二原始样本生成验收报告。

### 低压升温段、3A 覆盖区间与 21V 功率安全终点

终点条件是合取关系，必须同时满足：申请电压已经是 `21.0V`，校准请求电流是功率安全编码的 `2.850A`，并且电源实测电流低于 `3.000A`。21V 不允许请求 3A，因为 `21V × 3A = 63W` 超出本次授权电源的 60W 能力；因此报告必须同时展示终点前最后一个近 3A 满导通样本与 21V/2.85A 功率安全终点，不能把 2.85A 请求本身伪称为 3A 实测下降。这一对相邻证据定义了 60W 电源在 21V 上限下不能继续按 3A 预算供电的温度位置。

1. 从 `T_start` 到终点前的每个同步样本都必须有时间戳、板温、申请电压、电源实测电压、电源实测电流、门控 duty、合同电流和源端状态。这里的门控 duty 只允许在扫描/全速阶段为 `0%` 或 `100%`；`100%` 表示静态高电平，不是中间 PWM 波形。低压升温段允许实测电流低于 2.800A；这些点必须原样记录并标记为 `ramp_below_3a`，不能被伪装成近 3A 证据，也不能因此判定失败。
2. 定义 `t_3A_start` 为第一个满足以下全部条件的样本：`gateDuty=100%`、申请电流为 `3.000A`、非协商过渡、且 `2.800A <= sourceCurrentA <= 3.000A`；定义 `t_3A_last` 为 21V 终点之前最后一个满足同样条件的样本。这里的 2.800A 是“接近 3A”的下限（3A 减 200mA）。固定电压下板温升高会使实测电流暂时低于 2.800A；这类满导通样本必须标记为 `ramp_below_3a`，不能冒充近 3A 点，但不单独判失败。通过要求是 `t_3A_start` 与 `t_3A_last` 都存在，且 `t_3A_last` 的申请电压不低于此前任何有效近 3A 点；安全重协商期间允许短暂 gate duty 归零或请求回退，但必须显式标记、持续不超过 2s。扫描/全速阶段出现 `1–99%` duty，或把 `0%` 解释成低功率 PWM 而非安全关断，均取消该段证据资格。
3. 申请电压到达 `21.0V`、校准请求电流为 `2.850A` 后，必须取得至少两个连续、间隔不超过 2s 的同步满导通样本，且每个样本 `sourceCurrentA < 3.000A`、实测功率不超过 60W、板端实测 VIN 跟随 21V 请求、源端状态为 `ok`、profile 仍已应用。仅有协议 `100%` 导通而板端 VIN 已明显塌陷的样本无效。第一个满足全部条件的样本定义 `T_21V_terminal` 和 `t_21V_terminal`；它就是本次验收要报告的“21V 下电流不再按 3A 预算”的温度位置。
   PD 切换刚发生时，电源遥测可能短暂出现几十毫安的建立瞬态；这类样本必须保留在原始表中并标记为过渡，不得定义终点。报告渲染器将终点样本限定为已恢复负载态的 `sourceCurrentA >= 2.500A`，再与 `<3.000A`、满导通、VIN 跟随和 `status=ok` 条件合取。
4. 终点温度必须低于固件独立的 `220°C` 安全截止。A6 不要求在终点之后继续把电流维持在 3A，也不声称终点之后仍有 3A 加热能力。
5. 采样序列从室温到终点不得有未解释的时间空洞；相邻有效同步样本间隔必须不超过 2s。PD 重协商、传感器故障、源端掉线或设备重启直接取消通过资格；PPS gate duty 归零只有在已标记为不超过 2s 的安全重协商过渡时允许，归零表示静态安全关断而不是低功率 PWM。

### 阶段一校准提交判定（不等于 A6/HIL 通过）

只有以下条件全部满足，校准事务才可标记 `committed`；这一步不产生 A6/HIL `passed` 结论：

- `T_start <= 35°C`；
- 从冷态到 `21.0V/2.850A` 终点存在连续、可复核的同步序列，低压段明确标记为 `ramp_below_3a`；
- 存在 `t_3A_start` 和 `t_3A_last`，且 `t_3A_last` 是终点前最高申请电压的有效近 3A 点；低于 2.800A 的满导通升阻样本被标为 `ramp_below_3a`，没有被当作 3A 边界点；
- 21V/2.85A 功率安全终点有两个连续的满导通样本，`sourceCurrentA < 3.000A` 且实测功率不超过 60W，并记录 `T_21V_terminal`；
- 所有样本的实测输入功率不超过 60W，源端保持在线，设备没有重启或过温停机；
- 报告图表以秒为横轴，显示板温、申请电压、电源实测电压和电源实测电流，并标出 3A/2.8A 参考线、21V 终点和触发温度；原始样本表必须单独显示 `gateDuty`，并把 0%/100% 的静态门控语义与任何安全 blanking 区间标出，不能把门控 duty 直接标成“PWM 软启动”。

缺少 `t_3A_start` 或 `t_3A_last`、21V/2.85A 终点、把 `ramp_below_3a` 样本当作有效近 3A 点、只有 `contractMa=3000` 而没有电源实测电流、终点不是满导通，或 220°C 安全截止先触发，均只能标记 `failed`/`incomplete`，不能用 20V 的高电流片段替代。

### 阶段二通过条件（唯一的 A6/HIL 验收报告）

1. 阶段一已完成并成功读回 active calibration transaction/model identity；阶段二使用独立 `acceptanceRunId`、正常自动加热入口、`manualPpsEnabled=false` 和阶段一相同的 active model identity。
2. 阶段二从冷态开始，持续记录到自动安全边界或独立 `220°C` 安全截止；不得用阶段一的终端探针、阶段一的样本或人为指定 PPS 请求替代这段运行。自动控制选择的申请电压/电流必须原样记录，报告中的“边界温度”必须来自阶段二的实际同步样本。
3. 阶段二所有计入的 PPS Warmup/全速样本必须同时满足逻辑请求 `heaterRequestedOutputPermille=1000` 和确认合同后的物理 `heaterOutputPermille=1000` 静态全导通。协商/保护降压只能是明确标记的 `0%` 安全关断；任意未解释的 `1..99%` duty、PWM 软启动或用平均占空比替代申请电压，均使本轮报告 `failed`/`incomplete`。
4. 报告必须以阶段二原始连续序列为唯一数据源，按同一时间键绘制板温、申请电压、电源实测电压和电源实测电流，并显示 `2.8A` 与 `3.0A` 参考线。阶段二必须包含从冷态开始的连续全逻辑功率区间：该区间至少要有两个独立同步样本满足 `heaterRequestedOutputPermille=1000`、确认后的物理门控 `1000`、申请电流 `3.000A` 且电源实测电流在 `2.8–3.0A`；报告必须给出该区间的起止时间、板温和申请电压。随后，自动控制必须在阶段二实际应用的 v6 边界下推进到校准终端：申请 `21.0V/2.850A`，取得至少两个连续同步满导通样本，电源实测电流小于 `3.000A`，实测功率不超过 60W，且板端实测 VIN 跟随 21V。报告必须从这些阶段二原始样本给出终端温度 `T_21V_terminal`，并复核电流首次低于 `2.8A`（若在 220°C 前发生）的实际板温。只显示 `contractMa=3000`、只显示一个近 3A 点、只展示校准阶段终端探针、校准阶段数据、手动指定 PPS、回放或合成数据不能通过；缺少连续全逻辑功率证据或阶段二 21V/2.85A 实际应用证据时必须标记 `source_current_below_limit`、`terminal_boundary_not_applied` 或 `full_power_evidence_incomplete`。

220°C 仍是产品热模型标定的实时安全截止和独立产品门禁；它不是本 A6 3A 电流覆盖的强制终点。阶段二必须报告实际停止原因和停止温度，不能声称停止后仍保持 3A。
