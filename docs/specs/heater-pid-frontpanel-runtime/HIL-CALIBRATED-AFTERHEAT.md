## 临时ADC映射与新标定拒绝

主人给定室温约30°C，并授权在偏差超过3°C时临时调整假定绝对ADC偏移。A组保留实测3V3基准3328mV，将假定偏移从`−11000µV`改为既有允许范围下界`−20000µV`；应用启动停热读数29.22°C，后续冷态读数31.90°C。没有创建用户校准点；RTD与VIN用户样本仍全部为空。这个室温假定不是独立测温精度证明。旧热模型按映射变化失效，不能继续作为种子。
