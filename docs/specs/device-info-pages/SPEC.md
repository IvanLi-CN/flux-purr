# Flux Purr 160×50 设备信息三页规范

## 目的

设备信息页是只读的诊断档案，不是控制面板。用户进入页面后，应先看到页面主题和一个主事实，再按固定的行列读取身份、校准或运行状态。三页使用同一个几何网格、同一个字形资产和同一套语义颜色，避免每一页独立排版造成错位、拥挤或状态误读。

## 范围与非目标

本规范覆盖固件产品 renderer、固件 host preview 和 Web 前面板预览中的 `Identity`、`Calibration`、`Runtime` 三页。页面分辨率固定为 160×50，内容为英文短标签，左右短按翻页，中键返回上一级菜单。

本规范不改变校准算法、自然冷却、加热控制、风扇策略、EEPROM 格式或任何写入操作。页面只投影已经由运行时准备好的只读摘要；renderer 不访问硬件，也不执行阻塞 I/O。

## 设计意图与体验原则

1. **先主题、后事实。** 标题位于固定的页眉行，内容从统一的内容起点开始；用户不需要寻找每页的第一个字段。
2. **每页只有一个主视觉。** Identity 的主视觉是固件版本，Calibration 的主视觉是热模型状态，Runtime 的主视觉是运行时间。其他字段全部降为辅助行，不能与主视觉竞争。
3. **列先于文字。** 标签和值都落在固定列线上；字段长度变化只触发截断规则，不改变其他字段的位置。
4. **颜色表达语义，不表达装饰。** `success` 只表示已验证有效，`warning` 表示异常、缺失或未知；未知状态不得使用绿色。
5. **稳定的阅读节奏。** 内容行的顶部基线为 `16 / 28 / 37`，相邻行的间隔为 12px、9px；所有页都遵守这组三行节奏。页面不自动轮播，不增加额外分隔线。
6. **可回退。** 任意字段缺失显示 `--` 或规范中的未知状态；任何字符串都必须在自己的预算内结束，不能覆盖相邻字段、页脚圆点或容器边界。

## 几何合同

### 坐标系与容器

- 逻辑画布：`160×50`，原点在左上角，所有坐标均为整数逻辑像素。
- 内容面板：`x=4, y=1, width=152, height=45`，右边界为 `x=156`（半开区间）。
- 内容安全区：`x=12..148`，即左右各保留 8px 面板内边距；任何正文像素必须落在 `12 ≤ x < 148`。
- 页眉标题：左上角 `x=12, y=2`，使用 5×8 信息字形、1px 字间距。
- 唯一页眉分隔线：`x=12, y=12, width=136, height=1`。三页不得再绘制其他分隔线或容器线。
- 页脚页签：三个 5×2 圆角矩形位于 `y=47`，左端分别为 `70 / 79 / 88`；当前页使用 `accent`，其余使用 `border`。

### 网格与基线

| 轨道 | 顶部 y | 用途 | 字级 |
| --- | ---: | --- | --- |
| 主事实 | 14–25 | 页面唯一主值 | 6×10（固件 `Mid`，3×5 放大 2 倍） |
| 辅助行 1 | 28–35 | 第一组标签和值 | 5×8 信息字形 |
| 辅助行 2 | 37–44 | 第二组标签和值 | 5×8 信息字形 |

信息字形的字符 advance 固定为 6px（5px glyph + 1px 字间距），不得按字段临时改变字距。`Mid` 字形的 advance 固定为 8px（3px glyph ×2 + 1px 间隔 ×2）。

### 对齐规则

- 标签列左对齐到 `x=12`；同一列的所有标签使用同一字级和颜色。
- 单列值紧跟标签，间隔固定 6px；标签和值之间不得使用视觉上不一致的手工空格。
- 右列字段左端固定为 `x=84`，值左端固定为 `x=103`；右列不得向左侵入左列的值预算。
- 右对齐字段（SHA、板型）以 `x=148` 为右边界计算起点；不得通过改变字距来“塞入”字段。
- `Runtime` 的输出行使用两列：左列从 `x=12` 开始，右列从 `x=94` 开始；二者共享 `y=37` 基线。
- 任何字段的可见右边界必须小于等于 `148`；不得覆盖页脚 `y≥47` 的区域。

## 字体与字形资产

- 标题、标签、短状态、SHA、设备 ID、板型、复位和输出行使用项目修订后的 `FONT_INFO_5X8`，对应 5×8 点阵、6px advance。
- 每页只允许一个 6×10 主值：Identity=固件版本，Calibration=热模型状态，Runtime=运行时间。辅助字段不得升级为第二个主值。
- 6×10 主值使用现有 `BitmapFont::Mid` 3×5 字形的整数 2×缩放，不引入浏览器字体或非整数缩放。
- `0` 与 `T` 必须来自已修订的 5×8 资产；验收必须检查其笔画高度、宽度和相邻字符 advance 与 `A/S/E` 等字母一致。
- 超宽文本先按字段的最大字符数截断并加 `...`；仍然超宽时显示 `--`。禁止缩小字号、压缩字间距或覆盖其他字段。

## 颜色合同

颜色只能通过 `FrontPanelTheme` 的语义 token 取得：

| 语义 | Token | 用途 |
| --- | --- | --- |
| 背景/面板 | `background` / `panel` | 页面底色与内容面 |
| 主要文字 | `text` | 版本、ID、运行时间和正常只读值 |
| 辅助文字 | `muted` | 标签、板型、模型说明和非主状态 |
| 强调 | `accent` | 页面标题、SHA、当前页签 |
| 有效 | `success` | 仅 `VALID`、`SET` 等已验证状态 |
| 异常 | `warning` | `INVALID`、`MISSING`、`ERROR`、`UNKNOWN`、`UNAVAILABLE` |
| 边界 | `border` | 唯一页眉线和未选页签 |

深浅主题只改变 token 的 RGB565 值，不改变几何、字级或信息顺序。未知、缺失和无效状态都必须使用 `warning` 或 `muted`，不能使用 `success`。

## 页面内容与布局

### Identity

- 页眉：`IDENTITY`；开发构建在同一标题中显示 `IDENTITY / DEV`，由真实版本后缀决定。
- 主值：真实固件版本（去除后缀后的主体）位于 `x=12, y=16`，6×10；右边界不超过 `x=96`。
- 辅助主行：真实源码 SHA 前 7 位右对齐到 `x=148, y=16`，5×8，`accent`。
- 第一辅助行：`ID` 位于 `x=12, y=31`，设备 ID 值从 `x=30` 开始，最多 16 个字符。
- 同一行的板型右对齐到 `x=148, y=31`，`esp32-s3` 映射为 `S3`；缺失显示 `--`。
- 身份字段必须直接来自 `Identity`；不得生成看似真实的占位 MAC、SHA 或版本。

### Calibration

- 页眉：`CALIBRATION`。
- 主值：热模型状态位于 `x=66, y=14`，6×10；允许值为 `VALID`、`MISSING`、`INVALID`、`LEGACY`，超宽时按字段规则截断。
- 第一辅助行：左列 `RTD`/值（`x=12/31, y=28`），右列 `VIN`/值（`x=84/103, y=28`）；值允许 `SET`、`DEFAULT`、`INVALID`。
- 第二辅助行：左列 `CFG`/值（`x=12/31, y=37`），右列显示热模型来源（`x=84, y=37`），有效自然冷却模型才显示 `NATURAL`；否则显示原因状态。
- 只有通过自然冷却证据门禁的模型才可显示 `VALID` 与 `NATURAL`；renderer 不推断或修正状态。

### Runtime

- 页眉：`RUNTIME`。
- 主值：`UP` 标签位于 `x=12, y=17`，运行时间位于 `x=30, y=15`，6×10；格式为 `HH:MM:SS`，超过 99 小时切换为 `D HH:MM`。
- 第一辅助行：`RESET <reason>` 位于 `x=12, y=29`，最多 23 个 5×8 字符；原因只能是 `POWER ON`、`SW RESET`、`WATCHDOG`、`BROWNOUT`、`UNKNOWN`。
- 第二辅助行：左列 `HEATER <n>%` 从 `x=12, y=37` 开始，显示物理输出百分比；右列 `FAN ON/OFF` 从 `x=94, y=37` 开始，显示实际风扇命令。
- “允许加热”不能投影成非零输出；百分比必须来自实际输出状态。

## 交互与刷新

- 左右短按在 `Identity → Calibration → Runtime → Identity` 间循环。
- 中键短按或长按返回菜单；上、下及左右长按无副作用。
- 每次重新进入设备信息路由都从 `Identity` 开始，不自动轮播。
- 运行时间每秒更新；输出、校准和存储状态变化时刷新对应页摘要。
- 页面不提供写配置、控制加热或控制风扇的操作。

## 可评估验收

1. 固件和 Web 预览的三页都使用同一组面板、内容安全区、标题线、页签和行基线坐标。
2. 自动像素检查证明所有非背景像素（除面板和页签）均位于面板内；所有文本右边界 ≤148，正文不进入 `y≥47`。
3. Identity、Calibration、Runtime 各自只有一个 6×10 主值；所有辅助字段使用 5×8 信息字形和固定 6px advance。
4. 长版本、长 ID、未知校准状态、异常存储状态和 100% 加热输出均不裁切、不重叠、不改变其他字段坐标。
5. 深浅主题只改变颜色 token；截图对比不得出现几何差异。不得新增分隔线。
6. host 单元测试覆盖页码循环、重入归 Identity、状态颜色映射、时间格式、字段截断和文本边界；正式 renderer framebuffer 与 Web 预览均通过视觉证据检查。
