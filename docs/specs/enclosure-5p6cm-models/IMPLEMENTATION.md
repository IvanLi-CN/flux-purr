# Implementation

## Coverage

- Editable 5.6 cm enclosure sources live under `hardware/models/5p6cm/`.
- The shared joystick cap source lives at `hardware/models/flux-purr-Joystick.step`.

## Source State

STEP files provide cross-tool CAD exchange, and FCStd files preserve the FreeCAD-native projects. The repository does not currently track derived STL meshes, preview renders, or validation reports for these sources.

## Remaining Gaps

Print orientation, material choice, support strategy, mesh export, and heat-cycle fit validation remain bench-process decisions outside this source archive.
