# 校准图表数据悬浮交互

## Context and Scope

校准页面的温度—申请电压图和温度—时间图需要让操作者在查看曲线时读取当前 X 轴位置的数据，并能从图表中的离散观测回到右侧供电观测表。当前图表底部还显示一段与供电观测表重复的选中摘要，供电观测表在观测点增多时也必须保持可用的独立滚动区域。

## Goals

- 桌面端指针悬浮、移动端触摸/长按和键盘操作均可查看 X 轴位置对应的数据。
- 悬浮窗展示拟合曲线或温度轨迹在当前 X 轴位置的插值结果。
- 点击离散供电观测点时，右侧供电观测表聚焦并高亮对应行。
- 供电观测表在固定区域内独立垂直滚动，移动端支持横向查看完整列。
- 移除图表底部重复的选中观测摘要。

## Non-goals

- 不把插值结果写回设备或作为新的原始观测持久化。
- 不对拟合曲线有效范围之外的数据做外推。
- 不改变供电边界、RTD 换算或拟合算法本身。

## Requirements

### MUST

- `REQ-CHART-HOVER-INTERPOLATION`：在图表有效 X 轴范围内，指针或手指位置应映射到当前 X 值，并显示对应曲线的插值 Y 值；结果必须标明系列名称和单位。
- 温度—申请电压图的悬浮窗至少显示申请电压、拟合温度、合同电流/系列；温度—时间图至少显示时间、插值温度和阶段（环境、加热或自然冷却）。
- 同一 X 位置存在多个有效系列时，悬浮窗显示所有有效系列；无数据的系列不显示空值行。
- X 位置超出拟合曲线或温度轨迹的有效范围时，不得外推，并显示该位置无有效数据。
- 点击离散供电观测点时，图表点获得高亮，右侧供电观测表对应行获得选中状态并滚动到可见区域。
- 点击图表空白区域只更新悬浮窗，不改变右侧表格选中行。
- 悬浮窗附近显示垂直参考线和当前曲线/数据点高亮；靠近边缘时自动调整位置，不能溢出图表容器。
- 指针离开图表或触摸结束后关闭悬浮状态；点击图表后可保持当前悬浮状态，直到点击图表外或触摸结束。
- 供电观测表的标题和来源说明固定；表头固定；表体在限定高度内独立垂直滚动；移动端支持横向滚动。
- 移除图表底部 `thermal-chart__detail` 选中观测摘要及其重复图例说明。
- 图表必须支持键盘聚焦和左右方向键按 X 轴数据位置移动，并复用同一悬浮窗内容。
- 加载中、空数据或无有效换算数据时，不显示误导性的悬浮窗，并保留明确状态提示。

### SHOULD

- 悬浮窗中的插值结果与原始观测点使用不同视觉标识，避免混淆分析结果和实测数据。
- 选中表格行与图表离散点使用同一选中状态颜色。

## Domain model

- **图表交互位置（Chart Interaction Position）**：由指针、手指或键盘选择得到的 X 轴位置。
- **插值结果（Interpolated Result）**：在有效曲线范围内，根据图表数据计算出的当前 X 位置 Y 值；不是新的原始观测。
- **离散供电观测（Discrete Supply Observation）**：供电观测表中的一条原始采样记录，可由图表点选中。
- **选中观测（Selected Observation）**：当前被图表或表格选中的离散供电观测；图表点和表格行必须同步。
- **悬浮状态（Chart Hover State）**：包含当前 X 轴位置、有效系列插值结果、参考线和定位信息的临时 UI 状态。

## Verification

- 给定指针位于两条离散观测之间，悬浮窗显示拟合/轨迹插值结果，而不是最近离散点的值。
- 给定点击一个离散供电观测点，右侧表格对应行滚动到可见区域并高亮，图表点同步高亮。
- 给定供电观测点数量超过可视区域，表体可以独立滚动，页面和图表布局不被撑开。
- 给定指针靠近图表左右边界，悬浮窗仍完整显示在图表容器内。
- 给定离开图表或结束触摸，悬浮窗关闭；给定点击图表外，保持状态被清除。
- 给定截图箭头所示原底部摘要区域，页面不再渲染重复的选中观测摘要。
- 给定键盘聚焦图表，左右方向键可移动 X 轴位置并更新悬浮窗。

## Implementation notes

实现应复用现有 `TemperatureRequestChart`、温度轨迹图和 `SupplyObservationTable` 的数据口径；本规格只冻结交互、展示和联动行为，不冻结具体 SVG 命中测试或定位实现。
