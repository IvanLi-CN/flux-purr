# Web 标注区域局部视觉整理需求

## 依据与边界

需求依据为主人提供的热控工作台标注截图及对调整范围的确认。允许调整的范围严格限定为截图中的两个红色虚线框：顶部设备栏，以及标定页右下角包含运行状态和“停止自动校准”按钮的小区域。箭头和说明文字用于解释诉求，不扩大允许调整的范围。

框外元素的位置、尺寸、间距、样式和布局必须保持不变。不得通过移动框外元素、调整外部网格、改变相邻区域高度或扩大操作区来解决框内问题；全局样式修改不得产生框外影响。

## 顶部设备栏

- 减弱或去掉框内外层大卡片的视觉效果，解决大卡片内部继续嵌套小卡片的观感。
- 保留当前浅色工业拟物主题，通过控件质感、字体、配色及必要的层次表达设计风格。
- 保留设备选择、热板温度、PD 电压和模式切换的信息与操作能力。
- 框内整理不得改变顶部标题、下方导航或其他框外元素的布局。

## 标定页右下角操作区

- 仅优化框内运行状态与停止按钮的排布、对齐、间距和容器层次，改善局部观感。
- 操作区保留在截图标记的位置和范围内，不扩宽、不跨列、不改成整个标定内容区的通栏。
- 不移动或调整框外的图表、采样表、上方运行摘要与右侧日志。
- 保留状态信息、按钮含义、可用条件及既有操作行为，不改变标定流程或安全限制。

## 验收要求

- 在与参考截图相同的视口和内容状态下，两处框内的嵌套感与排布问题得到改善。
- 框外元素的位置、尺寸、间距、样式和布局与调整前一致；框内变化不得导致框外元素位移。
- 框内信息和操作保持清晰可读，控件不遮挡、不溢出允许调整的区域。
- 响应式适配仍遵守相同的组件边界，不通过改变框外布局解决框内拥挤。

## 文档状态

调整范围、主题方向与上述验收边界已经确认。框内实现采用去除顶部外层凹槽、去除标定操作区凹槽，并在保留状态与按钮上下排列的前提下让按钮填满现有内部宽度；容器原有 padding、gap 与外部布局保留。视觉验收以主人确认的当前候选截图为准。
