# Flux Purr v0.26.0

## Highlights

- Adds multi-level post-heating cooling with Off, Normal, and Fast modes.
- Adds multi-level heating overheat protection with Off, Low, Medium, and High modes.
- Exposes the two policies through the `FAN CTRL` front-panel screen and the Web control surface.
- Keeps the existing safety overrides and the legacy `activeCoolingEnabled` compatibility projection.

## Release scope

This release publishes the fan-policy implementation already integrated on `main` by pull request #103.
